## 从零实现 DMG Library（README 是产品方案，本次完成全部开发）

- 技术栈：Swift 6 + SwiftUI + AppKit + 系统 libsqlite3，**零三方依赖**。按 README 第 39 节建议做 Mac 原生，第一版不跨平台。
- 仓库已 git init 并提交（main 分支，commit 301722f）。

### 关键实现决策

- SQLite 通过 `Sources/CSQLite`（module.modulemap + shim.h）直接链接系统库，避免引入 GRDB 等依赖；WAL 模式 + 启动自动快照（保留 5 份）。
- SwiftPM 可执行 target 必须有 `main.swift`（不能只靠 `@main`），入口调用 `DMGLibraryApp.main()`。
- 本环境 SwiftPM 清单编译被沙箱拦截，构建/测试统一加 `--disable-sandbox`（已写入 build.sh）。
- 架构识别直接读 Mach-O / FAT 头（自写解析，不调 `lipo`），注意 `UnsafeRawPointer.loadUnaligned` 与 Swift 标准库同名方法冲突，直接用标准库版本即可（要求 `T: BitwiseCopyable`）。
- 图标提取用 ImageIO `CGImageSourceCreateThumbnailAtIndex` 直读 .icns，**不用 NSImage lockFocus**（后者非线程安全，会阻塞后台导入）；列表渲染走 NSCache 内存缓存，避免滚动时反复读盘。
- Finder「打开方式」在 SwiftUI App 生命周期下 NSApplicationDelegate 的 `openFile` 不回调，改为在 `applicationWillFinishLaunching` 里直接挂 `NSAppleEventManager` 的 `kCoreEventClass/kAEOpenDocuments`（冷启动读 `currentAppleEvent`，热启动走 handler）——已验证冷/热启动都能导入。
- `fileImporter` 的坑：传了 `allowsMultipleSelection` 参数时闭包是 `Result<[URL], Error>`，不传时是 `Result<URL, Error>`；显式标注闭包参数类型最稳。
- SwiftUI 里 `@Environment(SomeObservable.self)` 不能直接用 `$store.xxx` 投影，需手写 `Binding(get:set:)`。
- hdiutil 挂载耗时 1~3 秒，`store.mount` 必须 async 化，否则卡住主线程。

### UI 四项修复（用户反馈）

- 图标视图选中边框「重叠」：根因是 `GridCard` 固定 `width:132` 与 `LazyVGrid` 自适应列宽（112–160）不匹配，边框与内容错位。改为卡片 `frame(maxWidth:.infinity)` 撑满单元，填充与描边共用同一 `RoundedRectangle`，并加 hover 反馈。
- 添加按钮「不行」：SwiftUI `.fileImporter` 在工具栏/窗口组合下不可靠（面板不弹）。改用 `NSOpenPanel` 直接 `runModal()`（`ContentView.presentAddPanel` / `presentScanPanel`），EmptyState 与菜单命令通过 `.libraryAddFiles`/`.libraryScanFolder` 通知触发，已移除 `.fileImporter`，更稳。
- 分类选择位置不理想：详情面板原来的下拉 `Picker` 弹出位置飘、选中态不明显。换成内联胶囊选择器（复用 `FlowLayout`），选中项 `accentColor` 高亮 + 勾选，并支持就地「新建分类」。
- 备注保存交互差：原来「编辑/预览」互相切换会藏起编辑器且无反馈。改为常驻 `TextEditor` + 「预览」开关（叠在下方）+ 保存状态指示（自动保存 / 保存中… / 已保存），`scheduleSave` 防抖 0.6s 后回填 `saveState`。
- 清理上一轮排查冷启动遗留的 `AppDelegate.dbg` 日志与 `pendingPump` 定时器（`drainPendingURLs` 已直接导入，不再需要）。
