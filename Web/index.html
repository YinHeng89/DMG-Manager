Core Features

为「文件不动，信息清晰」而生

所有元数据与原始 DMG 彻底分离。你掌控文件名、内容与位置，DMG Library 只负责帮你管理认知。

文件零改动

只读挂载解析，原始 DMG 永不被重命名、移动或修改；删除只移除资料库记录。

自动解析

自动识别架构（ARM64 / Intel / Universal）、版本、Bundle ID、开发者、最低系统与图标。

版本库

同一软件的多版本自动折叠，列表默认显示最新；一键切换，包信息与状态随之更新。

标签与分类

自由打标签、建分类、写 Markdown 备注；常用标签一键追加，知识随手沉淀。

重复与失联检测

按 SHA-256 内容去重；文件移动或删除后自动标记失联，并可一键重新定位找回。

后台自动扫描

启动后后台扫描监控目录，与资料库比对只新增未入库的 DMG，不重复、不卡顿。

安装状态比对

自动比较 DMG 版本与 /Applications 中已装版本，提示「可升级 / 旧版本 / 未安装」。

菜单栏快速入口

搜索、添加、扫描、收藏与最近添加，全部从菜单栏一键直达，无需打开主窗口。

中英双语界面

内置简体中文与英文，可在「设置 → 通用」中随时切换，并支持浅色 / 深色外观。
